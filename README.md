# AI-Powered Smart Agriculture Monitoring System

## Overview

The AI-Powered Smart Agriculture Monitoring System is a web application that detects plant diseases from leaf images using Deep Learning. It helps farmers identify diseases quickly and provides treatment and prevention recommendations.

## Features

- Plant disease detection using AI
- Image upload functionality
- Disease prediction with confidence score
- Treatment and prevention suggestions
- Simple and user-friendly interface

## Technologies Used

- Python
- TensorFlow
- Keras
- MobileNetV2
- Streamlit
- OpenCV
- NumPy
- Pillow

## Dataset

- PlantVillage Dataset
- 38 plant disease classes
- Over 54,000 leaf images


## Installation

1. Clone the repository
2. Install the required packages

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
streamlit run app.py
```

## Workflow

1. Upload a plant leaf image.
2. The image is processed by the AI model.
3. The model predicts the disease.
4. The application displays the prediction, confidence score, and treatment recommendations.
